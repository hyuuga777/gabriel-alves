# Brief do Produto: Sistema de Gestão para Personal Trainer

## O Usuário Principal
Personal Trainer (Profissional) que atualmente usa planilhas complexas para gerenciar seus alunos, avaliações físicas e contratos.

## O Trabalho a ser Feito (Job-to-be-Done)
"Quando eu recebo um novo aluno ou realizo uma nova avaliação, eu quero registrar seus dados físicos e organizar seu treino rapidamente, para que eu possa acompanhar sua evolução, controlar vencimentos e entregar um serviço personalizado sem perder tempo com gestão manual de arquivos."

## Problemas Atuais (Planilha)
- Difícil acesso via mobile (durante o treino na academia).
- Risco de perda de dados ou corrupção do arquivo.
- Dificuldade em rastrear histórico de evolução de métricas e métodos aplicados (como as colunas vão crescendo horizontalmente).
- Gestão de vencimento manual (fórmula de dias restantes requer abrir o arquivo).
- Falta de controle de acesso adequado se precisar compartilhar parte dos dados.

## Menor Versão Útil (MVP)
Uma aplicação web restrita ao Personal (sem login para os alunos neste primeiro momento), com:
1. Cadastro de alunos com histórico de medidas e avaliações.
2. Controle simples de contratos (início, fim, valor e método de pagamento).
3. Histórico dos métodos de treino aplicados.
4. Importação segura da planilha atual para não perder histórico.
5. Visão geral (Dashboard) de alunos ativos e vencimentos próximos.
