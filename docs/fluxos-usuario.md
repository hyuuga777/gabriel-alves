# Fluxos de Usuário

## 1. Onboarding do Personal
- Login seguro (inicialmente admin/único usuário).
- Visualização do Dashboard com:
  - Alunos ativos.
  - Vencimentos próximos.
  - Alertas de reavaliação.

## 2. Gestão de Alunos (Anamnese)
- Adicionar novo aluno ou buscar existente.
- Preencher dados básicos: Nome, Sexo, Data de Nascimento.
- Preencher perfil: Objetivos, Dores/Intensidade, Limitações, Exercícios Proibidos.

## 3. Avaliações (Histórico)
- Inserir nova avaliação (Data).
- Preencher métricas: Peso, Altura, IMC, Percentual de Gordura, Testes (Anaeróbio, Aeróbio).
- Visualizar gráfico/tabela de evolução (comparação com avaliações anteriores).

## 4. Contratos e Vencimentos
- Inserir novo ciclo (Plano, Início, Fim, Valor, Meio de Pagamento).
- O sistema calcula e exibe dias restantes.

## 5. Histórico de Treino
- Selecionar método utilizado na sessão.
- Registrar data, observações e resultados/cargas.
