# Backlog MVP

## Épico 1: Fundação & Autenticação
- [ ] Configuração do projeto (Next.js, Banco de Dados, ORM).
- [ ] Autenticação simples para o Personal Trainer.
- [ ] Layout base e navegação.

## Épico 2: Gestão de Alunos
- [ ] Listagem de alunos com busca.
- [ ] Cadastro/Edição de aluno (Dados Base + Anamnese).
- [ ] Visualização do Perfil do Aluno.

## Épico 3: Avaliações Físicas
- [ ] Cadastro de Avaliação (Data, Peso, Altura, % Gordura).
- [ ] Cálculo automático de IMC.
- [ ] Tabela de histórico de avaliações no perfil do aluno.

## Épico 4: Contratos e Vencimentos
- [ ] Registro de Contrato/Plano (Início, Fim, Pagamento).
- [ ] Dashboard: Widget de contratos a vencer (em N dias).
- [ ] Dashboard: Widget de métricas gerais (alunos ativos).

## Épico 5: Métodos de Treino
- [ ] Cadastro de aplicação de Método de Treino (Data, Método, Obs).
- [ ] Visualização do histórico de treino no perfil do aluno.

## Épico 6: Importação de Dados
- [ ] Interface para upload da planilha (CSV/XLSX).
- [ ] Script de validação e simulação (Preview).
- [ ] Importação efetiva com relatório de erros e reconciliação.
